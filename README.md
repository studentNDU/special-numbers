Репозиторій містить приклади реалізації візуалізацій чисел спеціального типу засобами мови Python.  
Матеріали призначені для:
- супроводу наукової публікації;
- використання в освітньому процесі підготовки вчителів математики;
- відтворення та модифікації дослідницьких завдань з теорії чисел.

This repository contains examples of visualizations of special types of numbers implemented in Python.
The materials are intended for:
- supporting the accompanying scientific publication;
- use in the educational training of future mathematics teachers;
- reproducing and modifying research tasks in number theory.
